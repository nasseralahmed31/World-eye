
# عين العالم | Eye of the World

تطبيق Android تجريبي لرؤية الكاميرا والتعرف على الأشياء وعرض حدود نيون.

## المتطلبات
- JDK 17
- Gradle Wrapper متوافق مع Gradle 8.7
- Android SDK 34

## البناء

```bash
./gradlew assembleDebug
```

على Windows:

```bat
gradlew.bat assembleDebug
```

## مكان APK

```text
app/build/outputs/apk/debug/app-debug.apk
```

## الحالة الحالية

- معاينة الكاميرا: موجودة.
- واجهة النيون: أولية.
- تتبع الصناديق: متوفر كملف منفصل ويحتاج الربط.
- نموذج التقسيم: يحتاج ربطًا والتحقق من شكل مدخلاته ومخرجاته.
- تتبع الأقنعة الحقيقية: لم يكتمل بعد.

لا تعتبر النسخة جاهزة للاستخدام النهائي قبل بناء المشروع واختباره على جهاز حقيقي.
